# みぬくま（Minukuma）

面向日本租房场景的桌面浏览器扩展（Chrome / Edge / Brave，Manifest V3）。
实时解析房源页面数据，脱水表面虚标租金，估算实质月均成本，并在签约前精准标记潜藏的暗坑条件与避坑指南。处理全流程在浏览器本地完成，0 数据上传，保护用户隐私。

[原始产品规格](minukuma.md)

## 核心功能

1. **列表页（脱水月租 + 避坑徽章 + 快捷排雷）**：
   - 在房间价格旁展示按租期折算后的实质月均支出与差额；
   - **悬停微型明细卡（Hover Tooltip）**：鼠标悬停在徽章上直接浮现价格拆解（租金 + 管理费 + 摊销构成），无需跳出列表；
   - **直接标记暗坑**：`[🚨 LP瓦斯]`、`[⚠️ 木造]`、`[🚨 定期借家]`、`[1楼]`，翻页扫楼一眼排雷；
   - **吸顶悬浮排雷工具栏（Quick Filter Bar）**：在列表页顶部支持一键折叠隐藏木造或 LP 瓦斯房源，并实时统计已折叠数量。
2. **详情页（侦探透视抽屉）**：
   - 右上角常驻侦探小熊卡片，随页面平滑展开；
   - **💮 侦探综合评级印章（Minukuma Score）**：自动评出「太鼓判·优良」、「良好·推荐」、「普通·核实」、「要警戒·慎选」四档权威评级；
   - **初期费用水份透视条（Cost Stacked Bar）**：用绿/橙/蓝三色进度条直观透视“可退还押金” vs “纯损耗礼金/换锁” vs “固定服务费”的构成比例；
   - **外币参考折算**：支持在日元月租旁并列显示人民币（CNY）、美元（USD）或港币（HKD）参考折算；
   - **已知初期费用明细账**：押金、礼金、中介费、保证公司、火险及换算依据；
   - **📋 商务日文询盘模板生成器**：自动带入房源名称、URL 与针对性疑问（向中介确认 LP 瓦斯费用、定期借家续约、空室初期费用明细估价单、中介费打折磋商、外国人入居与保证公司咨询），支持一键复制到剪贴板。
3. **备选房源横向对比（Pocket Compare）**：
   - 详情页一键「＋加入对比」，最多支持同时保存 6 套心仪房源；
   - 点击「📊 查看对比」横向矩阵式比对实质月租、初期费用、到站时间、结构与评级，挑房决策快人一步。
4. **浏览器扩展弹出页（Popup）**：
   - 实时感知当前网页，若在三大租房网站显示激活状态，不在时提供主流平台快捷跳转；
   - 偏好设置：多语言切换（中 / 日 / 英）、灵活折算周期（12 / 24 / 36 个月）、外币换算偏好、列表避坑标签开关；
   - 日本租房四大避坑必看指南（LP 瓦斯、木造隔音、定期借家、敷引偿却）。

## 支持平台

目前已完整支持日本三大主流租房平台（**SUUMO**、**LIFULL HOME'S**、**at home**）的租赁列表页与房源详情页：
- **SUUMO** (`suumo.jp/chintai/*`)
- **LIFULL HOME'S** (`homes.co.jp/chintai/*`)
- **at home** (`athome.co.jp/chintai/*`)

## 本地运行与构建

需要 Node.js 22.18+ 和 npm。

```sh
npm install
npm test
npm run typecheck
npm run build
npm run zip  # 生成用于 Chrome 应用商店提交的 release zip 包
```

在 Chrome 打开 `chrome://extensions`，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择构建生成的 `.output/chrome-mv3` 文件夹。打开或刷新 SUUMO、LIFULL HOME'S 或 at home 的租房页面即可立即体验。

## 费用口径与计算规则

- **实质月均估算** = 月租 + 管理费 + 已识别的一次性不可退费用 ÷ 摊销月数（默认 24 个月，支持 12 / 24 / 36 个月切换）。
- **敷金与保证金**：计入初期需备现金总额。明确且可校验的敷引或偿却才计入月均摊销，初期费用小计不会重复计入。
- **金额未列明项**：在详情标记「待确认 / 要確認」，不凭空捏造费用。
- **中介费与保证会社**：可计算的仲介费月数按月租换算；初回保证料若按「賃料総額」百分比列示，试算基数使用月租与管理费之和。

## 技术架构

- **框架**：WXT (Manifest V3) + React 19 + TypeScript 5.9
- **样式隔离**：基于 Web Components Shadow DOM，确保不污染也不受宿主网站样式影响。
- **多语言**：内置中文、日本語和 English，根据浏览器语言自适应，并在本地持久化保存用户的偏好选择。
