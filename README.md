# みぬくま（Minukuma）

面向日本租房场景的桌面浏览器扩展。它从当前房源页面读取已展示的信息，估算月均租住成本，并标记签约前值得核实的房源条件。处理在浏览器内完成。

[原始产品规格](minukuma.md)

## MVP

先在 Chrome 上支持 SUUMO 租赁列表页和详情页。列表按房间显示月均估算和相对标价月租的差额，详情展开费用来源、初期费用和房源提示。筛选、排序、询盘文案以及 LIFULL HOME'S、at home 支持放在后续阶段。

## 费用口径

- 月均估算 = 月租 + 管理费 + 已知及按明确规则估算的一次性不可退费用 ÷ 24。按日元四舍五入，界面标注「24か月換算・概算」。
- 每项费用保留来源，区分页面明确标价、页面明确为零、按规则估算和未知。月租无法解析时隐藏估算。管理费、礼金等未知时，展示已知金额和缺项，避免把不完整的数字作为总价。
- 敷金单列在初期费用里。只有明确约定不可退的部分才进入月均摊销。初期费用小计列明覆盖项目，首期或按日计租金等未取得的项目单独标记。
- LP ガス、木造、定期借家和低楼层只提示已识别的条件，并保留原文依据。燃气账单差额和隔音表现不从标签推算。

## 实现结构

使用 WXT、React 和 TypeScript。首版内容脚本只匹配 SUUMO 的租赁页面，解析当前 DOM。适配器按房间提取字段和挂载点，共享计算模块只处理归一化数据。UI 按房间标识去重，并在列表更新后同步刷新。

1. 初始化扩展骨架，实现日元金额解析和费用计算。用固定样例验证「万円」「円」、明确为零、字段缺失和敷金摊销。
2. 验证 SUUMO 的真实列表及详情结构，收录精简 DOM 测试样例。详情页优先读取有明确标签的字段，列表识别失败时跳过该行。
3. 在 Chrome 加载未打包扩展，验证同楼多房、分页、动态重绘、重复注入和样式隔离，再进入其他平台适配。

当前阶段为设计与仓库初始化。扩展功能和实际网页兼容性待验证。
