# みぬくま（Minukuma）

面向日本租房场景的桌面浏览器扩展。它从当前房源页面读取已展示的信息，估算月均租住成本，并标记签约前值得核实的房源条件。处理在浏览器内完成。

[原始产品规格](minukuma.md)

## 支持平台

目前已完整支持日本三大主流租房平台（**SUUMO**、**LIFULL HOME'S**、**at home**）的租赁列表页与房源详情页：
- **列表页**：在每个房间旁显示 24 个月折算的实质月均成本徽章（以及相比标价月租的差额）。
- **详情页**：右上角展开「みぬくま」抽屉卡片，展示已知初期费用明细、费用折算依据与避坑提示。
- 筛选、排序以及询盘文案功能放在后续阶段。

## 本地运行

需要 Node.js 22.18+ 和 npm。

```sh
npm ci
npm test
npm run typecheck
npm run build
```

在 Chrome 打开 `chrome://extensions`，打开开发者模式，点击「加载已解压的扩展程序」，选择 `.output/chrome-mv3`。打开或刷新 SUUMO、LIFULL HOME'S 或 at home 的桌面版租赁列表和详情页。

详情页右上角的「みぬくま」按钮可展开费用卡片。界面支持中文、日本語和 English，默认跟随 Chrome 界面语言（其他语言回退到日文）。卡片里的语言选择会保存在扩展本地，并应用到列表徽章。

## 费用口径

- 月均估算 = 月租 + 管理费 + 已识别的一次性不可退费用 ÷ 24。列表只包含当前列表行里的费用，详情可使用页面明确列出的其他初期费用。
- 金额无法解析的项目在详情标记「要確認」。SUUMO 摘要费用栏的 `-` 按未列出收费处理，原文保留在详情。月租无法解析时跳过该房间。
- 敷金与保证金计入初期费用小计。明确且可校验的敷引或償却才计入月均摊销，初期费用小计不会重复计入。小计不含首期房租和按日计租金。
- 可计算的仲介费月数按月租换算。初回保证料若按「賃料総額」的百分比列示，试算基数使用月租与管理费之和，实际基数可向中介确认。
- 详情保留已识别的 LP ガス、木造、定期借家、低楼层和其他费用原文，方便核对房源条件。

## 实现结构

WXT 将 React 和 TypeScript 打包为 Manifest V3 扩展。SUUMO 适配器读取页面中的房间行和详情字段，共享费用模块只处理归一化数据。内容脚本为每个房间的价格单元格挂载一个徽章，观察列表变化并更新或移除对应徽章。扩展界面使用 Shadow DOM 隔离样式。
